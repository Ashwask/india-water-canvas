# India Water Canvas · Privacy notice

**v1.0 · 2026-05-08**

The India Water Canvas is a static web artefact hosted in the public GitHub repository `Ashwask/RFPartnerMap`. This notice describes what data the artefact collects, what it does with that data, and what choices you have.

## What this artefact collects from you

**Nothing on the artefact itself.** The dashboard (`Water/dashboard.html`) is a static HTML file. There is:

- **No analytics.** No Google Analytics, no Mixpanel, no Plausible, no Matomo. The author does not log your visits.
- **No cookies.** The artefact uses `localStorage` to remember your audience preference (CSO / NGO / Philanthropy / CSR / Corporate / Citizen). This is stored in your browser only; it is not transmitted to any server. You can clear it by clearing your browser site data.
- **No login.** No account; no email collected; no IP-tracking on the artefact's pages.
- **No fingerprinting.** No device-fingerprinting or behavioural profiling.

## What third-party services receive data when you load the page

Loading the dashboard fetches assets from third-party CDNs:

- **OpenStreetMap tiles** — your IP + the map tiles you view are visible to OpenStreetMap. See [openstreetmap.org/copyright](https://www.openstreetmap.org/copyright).
- **unpkg.com** (Leaflet library) — your IP is visible during page load.
- **cdn.jsdelivr.net** (Chart.js, d3-sankey libraries) — your IP is visible during page load.
- **d3js.org** — your IP is visible during page load.
- **github.com / githubusercontent.com** — when the artefact is hosted on GitHub Pages or the source files are loaded directly from GitHub, GitHub may collect access logs per its [privacy statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement).

The author has no control over the privacy practices of these third parties. If this is a concern, you may host the dashboard on your own server with locally-cached library files; CC BY-NC 4.0 permits this.

## What you give back through GitHub issues

When you click "Submit a correction" or any "↑ Give" button in a role panel, you are taken to **GitHub** to open an issue. GitHub then collects the data you submit (including your GitHub identity) under [GitHub's privacy practices](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement). The artefact author then sees your issue (along with anyone visiting the public repository).

You can submit issues anonymously by creating a fresh GitHub account or contacting the author directly via email (request via repo issue) for sensitive contributions.

## Reviewers + named contributors

Reviewers who sign off on methodology + named external reviewers are listed publicly in `review-log.md` with their consent. Authors of contributions (corrections, observations, story tips, partner-table additions) are credited unless they explicitly request anonymity.

## Data downloads

The CSV/JSON files in `Water/data/` are open data. Downloading them does not record any tracking on the author's side.

## Reviewer / contributor disclosures

The author records reviewer and contributor disclosures (e.g., funding relationships with named actors) where they affect the artefact's claims. These disclosures are public. By offering review or contribution with a public byline, you accept that your name + relevant affiliations may be recorded for transparency.

## Changes

Material changes to this notice are recorded in `changelog.md`. Continued use after changes constitutes acceptance.

Open an issue at <https://github.com/Ashwask/RFPartnerMap/issues> for any privacy question.
