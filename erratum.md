# India Water Canvas — Erratum log

When a correction is accepted, it is recorded here with: date · what changed · what the source was · which audience it most affected. Permanent record so users can trace the artefact's history.

For the resolution process, see [review-log.md](review-log.md). For raw corrections, see GitHub issues.

## How to flag an issue

1. Open an issue at the parent repository: <https://github.com/Ashwask/RFPartnerMap/issues/new>
2. Tag with: `correction` · `methodology-question` · `source-update` · `dispute` · `suggestion`
3. State: which section · which claim · proposed correction · evidence
4. Author response within 14 days; tracked in this log

The artefact's job is to be correctable. Errata are a credibility marker, not a failure.
